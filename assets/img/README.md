Tips:
- Export as JPG, quality ~80. Keep each file under ~400 KB.
- Long side 1600–2000 px is plenty for web.
- On macOS you can batch-resize in Preview: select files → Tools → Adjust Size.
  Or with ImageMagick: `mogrify -resize 1600x -quality 80 *.jpg`
